# mi-galeria-web
# Galería de Perros

Aplicación web dinámica que muestra razas de perros con imágenes reales, buscador, categorías y favoritos. Desarrollada como proyecto final de la Unidad 1 de Programación Front End (TI3V31).

## 🌐 Sitio publicado

👉 [https://jennygonavia.github.io/mi-galeria-web/](https://jennygonavia.github.io/mi-galeria-web/)

## ✨ Funcionalidades

- Galería de 60 razas con imágenes obtenidas desde la API pública Dog CEO
- Buscador en tiempo real por nombre de raza
- Filtro por categorías: razas pequeñas, razas grandes y favoritos
- Modal con detalle de cada raza e imágenes adicionales
- Sistema de favoritos durante la sesión
- Paginación con 8 tarjetas por página
- Diseño responsivo adaptado a móvil y escritorio

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 con variables, Grid, Flexbox y media queries
- JavaScript con Fetch API y async/await
- Git y GitHub Pages

## 📡 API utilizada

[Dog CEO Dog API](https://dog.ceo/dog-api/) — gratuita, sin clave requerida.
